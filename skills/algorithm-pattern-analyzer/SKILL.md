# Algorithm Pattern Analyzer Skill

## Overview
Inspects problem constraints, input topologies, and mathematical requirements to identify optimal algorithmic patterns (DP, Graph, Range Query, Greedy).

## Operations
1. Extracts constraints ($N, M$, time limit, memory limit) to establish the asymptotic bound.
2. Identifies subproblem overlap, optimal substructure, and monotonicity properties.
3. Maps problem statements to standardized canonical handbook classifications.
4. Highlights initial naive bottlenecks and outlines the optimization path.
